# Dependency Rules

- Dependencies point toward stable domain and declared contract layers.
- Cross-platform clients share contracts, not UI or runtime-specific internals.
- Cycles, duplicate contract ownership, and hidden database access are drift.
- New dependencies require purpose, owner, security/license review, and verification.
- Existing repository conventions remain authoritative unless a verified correction plan replaces them.
